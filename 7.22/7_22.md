
### 리스트의 가변성

생성 후에도 값을 변경 가능(수정, 추가, 삭제)

1. 인덱싱으로 값 수정하기
    1. my_list[1] = ‘two’
2. 슬라이싱으로 여러 값 한번에 바꾸기
    1. my_list[2:4] = [’three’, ’four’]

### 튜플

여러 개의 값을 순서대로 저장하는 변경 불가능한 시퀀스 자료형

- * 단일 요소 튜플을 만들 때는 후행 쉼표 쓰기 ex.(1,)
- 한번 생성된 튜플은 내용을 절대 수정, 추가, 삭제할 수 없음
- 튜플은 python 내부 동작과 안전한 데이터 전달에 사용(개발자가 자주 사용하진 않음)

### range

연속된 정수 시퀀스를 생성하는 변경 불가능한 자료형

- 주로 반복문과 함께 사용, 특정 횟수만큼 코드를 반복 실행할 때 유용
- 실제 모든 숫자를 메모리에 저장하는 대신, 시작 값, 끝 값, 간격이라는 규칙만 기억해 메모리 사용에 효율적
- 기본 구문 - range(start, stop, step)

### dict

key - value 쌍으로 이루어진 순서와 중복이 없는 변경 가능한 자료형

- 중괄호 {} 안에 값들이 쉼표로 구분

### 딕셔너리의 규칙

- key의 규칙
    - 고유해야함
    - 변경 불가능한 자료형만 사용가능(str, int, float, tuple)
- value의 규칙
    - 어떤 자료형이든 가능

### 딕셔너리 갑 접근 방법

- key를 사용해 value를 꺼내올 수 있음
    - ex. 딕셔너리[key] ⇒ value
- 값 추가 및 변경

```python
my_dict = {'apple': 12, 'list': [1, 2, 3]}
# 추가
my_dict['banana'] = 50
print(my_dict)  # {'apple': 12, 'list': [1, 2, 3], 'banana': 50}

# 변경
my_dict['apple'] = 100
print(my_dict)  # {'apple': 100, 'list': [1, 2, 3], 'banana': 50}
```

### set

순서와 중복이 없는 변경 가능한 자료형

- 중괄호 {} 안에 값을 표현
but 딕셔너리와 구분을 위해 my_set = set()로 생성
- 집합과 동일한 연산 처리 가능

### 세트의 집합 연산

```python
my_set_1 = {1, 2, 3}
my_set_2 = {3, 6, 9}

# 합집합
print(my_set_1 | my_set_2)  # {1, 2, 3, 6, 9}

# 차집합
print(my_set_1 - my_set_2)  # {1, 2}

# 교집합
print(my_set_1 & my_set_2)  # {3}
```

### 형 변환(type)

- 한 데이터 타입을 다른 데이터 타입으로 변환하는 과정
    - 암시적 형변환 : 파이썬이 자동으로 처리
        - ex.  정수와 실수의 연산, Boolean과 Numeric Type에서만 가능
    - 명시적 형변환 : 개발자가 직접 처리 ⇒ 외우는게 아니라 마주하면서 깨닫기

### 연산자

- 비교 연산자
    - == 연산자
        - 값(데이터)이 같은 지를 비교
        ex) 1 == True ⇒ True
    - is 연산자
        - 두 변수가 완전히 동일한 객체를 가리키는지, 즉 메모리 주소가 같은지를 확인할 때 사용
        - 주로 싱글턴 객체를 비교할 때 사용
            - 싱글턴 객체 : 오직 1개만 존재하도록 만들어진 객체, 항상 같은 메모리 주소를 가짐(None, True, False)
- 논리 연산자 : 여러 개의 조건을 조합하거나, True/False 값을 반대로 뒤집을 때 사용(ex. and, or, not)
    - 비교 연산자와 함께 사용 가능

### 단축 평가

논리 연산에서 두 번째 피연산자를 평가하지 않고 결과를 결정하는 동작

- 코드 실행을 최적화하고, 불필요한 연산을 피할 수 있도록 함

```python
# 단축 평가

# 1
item1 = '지도'
item2 = '나침반'
# result에 item1과 item2를 넣는 것이 아니라 and 연산 먼저!!!
result = item1 and item2
print(f'최종적으로 챙긴 물건: {result}')
# >> 최종적으로 챙긴 물건: ??

# 2
item1 = '지도'
item2 = ''
result = item1 and item2
print(f'최종적으로 챙긴 물건: "{result}"')
# >> 최종적으로 챙긴 물건: ??

# 3
item1 = ''
item2 = '나침반'
result = item1 and item2
print(f'최종적으로 챙긴 물건: "{result}"')
# >> 최종적으로 챙긴 물건: ??

```

# 강사님 Review

### 중첩 리스트

- 리스트 안에 리스트가 또 들어가는 경구
- 리스트를 복사할 경우 메모리 주소값이 같아서 원본 훼손을 막기 위해 깊은 복사를 함

**복사가 아닌 경우**

```python
l1 = [1,2,3,[4,5,6]]
l2 = l1
id(l1)
id(l2)
# 둘이 같은걸 알 수 있음
# why?? => 같은 메모리 주소를 "참조"하기 때문
```

![모든 list가 원본과 같은 곳을 가르켜 무조건 훼손](attachment:8c905196-ec02-442e-86a0-c5f572d3a5fd:image.png)

**얕은 복사**

```python
l1 = [1,2,3,[4,5,6]]
l3 = l1.copy()
id(l1[3])
id(l3[3])
```

![얕은 복사는 첫list(가장 바깥)만 새로 주소를 만들고 안은 같은 주소
여전히 원본 훼손 우려 있음](attachment:f240df10-8cc5-41e2-95a3-74503461ee14:image.png)

**깊은 복사**

```python
import copy
l1 = [1,2,3,[4,5,6]]
l4 = copy.deepcopy(l1)
id(l1)
id(l4)
```
